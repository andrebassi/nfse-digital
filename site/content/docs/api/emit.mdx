`POST /invoices` emite a NFS-e na SEFIN. Campos vazios vêm do modelo de serviço: o valor padrão, a competência de hoje e a descrição com `{mes}` e `{ano}` resolvidos.

<Tabs items={['cURL', 'Go', 'Python', 'TypeScript']}>
<Tab value="cURL">
```bash
curl -X POST https://nfse.bassi.engineer/api/v1/invoices \
  -H "Authorization: Bearer $NFSE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "idempotency_key": "fatura-2026-11-0042",
    "customer_id": 1,
    "template_id": 1,
    "amount": "1500.00",
    "description": "Suporte técnico - novembro"
  }'
```
</Tab>

```go
import nfse "github.com/andrebassi/nfse-digital/sdk/go"
```

## Corpo

| Campo | Obrigatório | Formato | Vazio significa |
|---|---|---|---|
| `idempotency_key` | sim | texto, estável por cobrança | 422 |
| `customer_id` | sim | inteiro (`GET /customers`) | 422 |
| `template_id` | sim | inteiro (`GET /templates`) | 422 |
| `amount` | não | `1500.00` ou `1.500,00` | valor padrão do modelo |
| `competence` | não | `AAAA-MM-DD` | hoje (America/Sao_Paulo) |
| `description` | não | texto | descrição do modelo, com `{mes}` e `{ano}` resolvidos |
| `confirm_production` | só em produção | boolean | `false` → 409 com o emitente em produção |

Campo que não está na tabela é recusado com **400**: um `confirmProduction` digitado errado não passa calado.

## Respostas

| Status | Quando | O que fazer |
|---|---|---|
| **201** | nota nova; `status` é `authorized` ou `rejected` | rejeitada: leia `error_code` e `message`, corrija o cadastro e emita com **outra** chave |
| **200** | a `idempotency_key` já tinha nota | nada foi emitido; é a mesma nota da primeira chamada |
| **202** | SEFIN sem resposta definitiva; `status` = `pending` | [consulte pela chave](./query) antes de qualquer nova tentativa |
| **409** | emitente em produção sem `confirm_production: true` | peça confirmação a uma pessoa e repita com o campo |
| **422** | dado inválido; `fields` diz o problema por campo | corrija o campo apontado |

A resposta **201** traz o cabeçalho `Location` com a URL da nota.
