API REST (integração de sistemas)

Integre seu sistema (ERP, faturamento) para emitir, listar, consultar e cancelar notas. Tomadores e modelos de serviço continuam sendo cadastrados aqui no painel; a API só os lista.

Toda emissão leva uma idempotency_key sua (ex.: o id da fatura). Ela é a chave de idempotência: reenviar a mesma chave nunca emite outra nota, devolve a mesma. E você consulta a nota por ela ou pelo id.

{{$base}}

Autenticação

Exemplo

{{- if eq $d.APIOp "emit"}}curl -X POST {{$base}}/invoices \
  -H "Authorization: Bearer {{$tok}}" \
  -H "Content-Type: application/json" \
  -d '{
    "idempotency_key": "fatura-2026-11-0042",
    "customer_id": {{$d.APICustomerID}},
    "template_id": {{$d.APITemplateID}},
    "amount": "1500.00",
    "description": "Suporte técnico - novembro"
  }'
{{- else if eq $d.APIOp "show"}}# pela chave da emissão (o id da fatura no seu sistema)
curl "{{$base}}/invoices/by-key?idempotency_key=fatura-2026-11-0042" \
  -H "Authorization: Bearer {{$tok}}"

# ou pelo id da nota
curl {{$base}}/invoices/42 \
  -H "Authorization: Bearer {{$tok}}"
{{- else if eq $d.APIOp "list"}}curl "{{$base}}/invoices?status=authorized&limit=20" \
  -H "Authorization: Bearer {{$tok}}"
{{- else}}curl -X POST {{$base}}/invoices/42/cancel \
  -H "Authorization: Bearer {{$tok}}" \
  -H "Content-Type: application/json" \
  -d '{
    "reason": "erro_emissao",
    "description": "Valor da fatura informado errado"
  }'
{{- end}}
