## Story

As a dono do emissor, I want entrar no painel com Touch ID, Windows Hello ou chave de segurança, so that eu não dependa de senha para abrir o emissor.

## Acceptance Criteria

1. Configurações → aba **Segurança** (`/settings/security`): cadastrar passkey, ver quantas existem (com criação e último uso) e remover todas.
2. Login: **Entrar com passkey**, sem digitar e-mail (passkey descobrível).
3. Desafio no servidor, de uso único, válido por 5 minutos; assinatura, origem e contador conferidos no servidor.
4. Passkey de outra conta ou assinatura de outra chave não entra.
5. Configurações em abas por rota: `/settings` (Emitente), `/settings/certificate`, `/settings/security`.

## Dev Notes

- **RP ID = `localhost`.** O WebAuthn não aceita endereço IP; a passkey funciona em `http://localhost:<porta>`. Aberta por `127.0.0.1`, a aba Segurança mostra o link para localhost.
- **Desvio da 4.3 (AC 7, "sem JavaScript próprio"):** WebAuthn só existe como API do navegador. Entrou um único arquivo, `/static/passkey.js`, servido pelo painel (CSP `script-src 'self'`, nenhum script externo). Toda decisão fica no Go.
- A credencial guardada é a chave **pública** e o contador; a privada nunca sai do aparelho.

### Testing

Autenticador por software no teste (`passkey_test.go`): chave P-256, `attestationObject` "none" em CBOR e assinatura ECDSA do login — o servidor confere como faria com um aparelho real.
